# জমি যাচাই (Jomi Jachai) — ল্যান্ডটেক ২০২৬

> **জমি কেনার আগে ১০ সেকেন্ডে জানুন নিরাপদ কি না**  
> ক্রিপ্টোগ্রাফিক সুরক্ষা ও উন্মুক্ত নাগরিক ভূমি যাচাই প্ল্যাটফর্ম।

---

## 📌 প্রকল্পের পরিচিতি ও সমস্যা (P5: Check Before You Buy)

বাংলাদেশে জমি ক্রয়-বিক্রয়ে সাধারণ নাগরিকরা প্রায়শই ভয়াবহ প্রতারণার শিকার হন। ভূমি বিরোধের কারণে দেশে লক্ষ লক্ষ দেওয়ানি মামলা চলমান এবং প্রতি বছর হাজার কোটি টাকার আর্থিক ক্ষতি হয়।

মূল সমস্যাগুলো হলো:
1. **জাল ও পরিবর্তিত দলিল**: রেজিস্ট্রি অফিসের বাইরে দলিলের কাগজের তথ্য বা জমির পরিমাণ গোপনে পরিবর্তন।
2. **দ্বৈত বিক্রয় (Double Sale)**: একই দাগের জমি একাধিক ক্রেতার কাছে বিক্রি করে দলিল তৈরি করা।
3. **ভুয়া মালিকানা (Non-Owner Sale)**: খতিয়ানের মূল মালিকের পরিবর্তে অন্য ব্যক্তি বা জাল পাওয়ার অব অ্যাটর্নি দিয়ে বিক্রয়।
4. **অতিরিক্ত জমি বিক্রয়**: খতিয়ানে যে পরিমাণ জমি অবশিষ্ট আছে, তার চেয়ে বেশি জমি বিক্রি দেখানো।
5. **সরকারি খাস জমি বিক্রয়**: খাস জমি সাধারণ মালিকানাধীন দাবি করে প্রতারণা।
6. **বন্ধকী বা মামলাধীন জমি গোপন রাখা**: ব্যাংকে ঋণ নিয়ে বন্ধক রাখা জমি বা আদালতে বিচারাধীন সম্পত্তি গোপন রেখে বিক্রি।

**জমি যাচাই** প্ল্যাটফর্মটি এই সমস্যার সমাধানে **P2 Verification (ডিজিটাল সততা যাচাই)** এবং **P3 Fraud Checks (স্বয়ংক্রিয় জালিয়াতি শনাক্তকরণ)** প্রয়োগ করে **P5 (Check Before You Buy)** সেবা প্রদান করে। একজন ক্রেতা কোনো বায়না বা অর্থ প্রদানের পূর্বে মাত্র ১০ সেকেন্ডে দলিলের নম্বর, দাগ নম্বর বা QR কোড স্ক্যান করে ভূমির নিরাপত্তা যাচাই করতে পারেন।

## ⚙️ কীভাবে কাজ করে (How It Works)

সিস্টেমটি প্রতিটি অনুসন্ধানের বিপরীতে রিয়েল-টাইমে ৭-স্তরের নিরাপত্তা নিরীক্ষা চালায়:

```
[নাগরিক অনুসন্ধান] (দাগ নম্বর / দলিল নম্বর / QR কোড স্ক্যান)
       │
       ▼
[১. ক্রিপ্টোগ্রাফিক হ্যাশ যাচাই (SHA-256)]
   Formula: sha256(deed_no | dag_no | seller | buyer | area | deed_date | prev_hash)
   ↳ ১ অক্ষর বা ১ শতক পরিবর্তন হলেও হ্যাশ অমিল শনাক্ত করে লাল সংকেত দেয়।
       │
       ▼
[২. দ্বৈত বিক্রয় নিরীক্ষা (Double Sale Check)]
   ↳ একই দাগে একাধিক সক্রিয় বিক্রয় দলিল বা নামজারিবিহীন চুক্তি শনাক্ত করে।
       │
       ▼
[৩. খতিয়ানভুক্ত মালিকানা মিলকরণ (Owner Matching)]
   ↳ লেভেনশটাইন দূরত্ব ও বাংলা নাম নরমালাইজেশনের মাধ্যমে বিক্রেতা মূল মালিক কি না যাচাই করে।
       │
       ▼
[৪. অবশিষ্ট জমির পরিমাপ যাচাই (Area Check)]
   ↳ বিক্রীত জমির পরিমাণ খতিয়ানের অবশিষ্ট সীমার অতিরিক্ত কি না যাচাই করে।
       │
       ▼
[৫. নামজারি স্থিতি নিরীক্ষা (Mutation Status Check)]
   ↳ সহকারী কমিশনার (ভূমি) অফিস কর্তৃক নামজারি ও জমাভাগ সম্পন্ন হয়েছে কি না নিশ্চিত করে।
       │
       ▼
[৬. সরকারি খাস জমি ফিল্টার (Khas Land Protection)]
   ↳ খাস জমি সাধারণ ক্রেতার কাছে বিক্রয় সম্পূর্ণ নিষিদ্ধ করে লাল সংকেত দেয়।
       │
       ▼
[৭. দায় ও বন্ধক যাচাই (Encumbrance Check)]
   ↳ জমি কোনো ব্যাংকে বন্ধক বা আদালতে মামলাধীন কি না যাচাই করে।
       │
       ▼
[ট্রাফিক লাইট সিদ্ধান্ত]
   🟢 সবুজ (নিরাপদ জমি)
   🟡 হলুদ (সাবধান — নাম বা বন্ধকী যাচাই প্রয়োজন)
   🔴 লাল (ঝুঁকিপূর্ণ — জমি কেনা থেকে বিরত থাকুন)
```

## 🏢 কর্মকর্তা পোর্টাল (Officer Portal)

কর্মকর্তাদের জন্য `/officer` রুটে একটি সংরক্ষিত প্ল্যাটফর্ম রয়েছে:
- **সহজ পাসকোড সুরক্ষা**: সিম্পল পাসকোড ও সিকিউর `httpOnly` সেশন কুকির মাধ্যমে অ্যাক্সেস নিয়ন্ত্রিত।
- **নতুন দলিল নিবন্ধন (`/officer/register`)**:
  - স্বয়ংক্রিয় ক্রমিক দলিল নম্বর (যেমন: `DEED-1010`)।
  - বাংলা সংখ্যা স্বয়ংক্রিয়ভাবে রূপান্তর।
  - খতিয়ানের অস্তিত্ব ও বৈধতা যাচাই।
  - পূর্ববর্তী দলিলের লিঙ্ক (`prev_hash`) ধরে ক্রিপ্টোগ্রাফিক হ্যাশ তৈরি ও সংরক্ষণ।
  - তাৎক্ষণিক QR কোড জেনারেশন ও ডাউনলোড সুবিধা।
- **নামজারি অনুমোদন (`/officer/mutation`)**:
  - অপেক্ষমাণ সক্রিয় দলিলের তালিকা।
  - এসি ল্যান্ড কর্তৃক এক ক্লিকে খতিয়ানে নতুন মালিকের নাম প্রতিস্থাপন ও অবশিষ্ট জমি সমন্বয়।
- **ইন্টারেক্টিভ জালকরণ ডেমো ল্যাব (`/officer/demo`)**:
  - নিরাপদ ডেমো দলিলে (`DEED-1001`, `DEED-1002`, `DEED-1003`) জমির পরিমাণ গোপনে ১ শতক পরিবর্তন করে সিস্টেম কীভাবে হ্যাশ অমিল ধরে তা প্রদর্শনের সুবিধা।
  - এক ক্লিকে পূর্বের অবস্থায় ফিরিয়ে আনার (`restore`) ব্যবস্থা।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **ফ্রেমওয়ার্ক**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, Partial Prerendering, Proxy Architecture)
- **ইউজার ইন্টারফেস**: [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/) (মোবাইল-ফার্স্ট, উচ্চ বৈসাদৃশ্য, বাংলা লাইট থিম)
- **ডাটাবেস ও স্টোরেজ**: [Supabase](https://supabase.com/) (PostgreSQL with Row Level Security & Server-Side Client)
- **ক্রিপ্টোগ্রাফি**: Node.js `node:crypto` (SHA-256 Digests)
- **নাম প্রসেসিং**: `fastest-levenshtein` (বাংলা নাম ও উপাধি ভ্যারিয়েশন হ্যান্ডলিং)
- **কিউআর কোড**: `qrcode` (সার্ভার-সাইড ডাটা ইউআরএল জেনারেশন) এবং `html5-qrcode` (ক্যামেরা ভিত্তিক ব্রাউজার স্ক্যানার)
- **ভাষা ও ফন্ট**: সম্পূর্ণ বাংলা ইউজার ইন্টারফেস, [Noto Sans Bengali](https://fonts.google.com/specimen/Noto+Sans+Bengali) ফন্ট

## 🚀 লোকাল পরিবেশে চালানোর নির্দেশিকা (Local Setup)

### ১. প্রয়োজনীয় সফটওয়্যার
- [Node.js](https://nodejs.org/) (ভার্সন ২০ বা তদূর্ধ্ব)
- `npm`

### ২. রিপোজিটরি ক্লোন ও ডিপেন্ডেন্সি ইনস্টলেশন
```bash
git clone https://github.com/irfanulhoquetaseen/jomi-jachai.git
cd jomi-jachai
npm install
```

### ৩. পরিবেশ ভ্যারিয়েবল কনফিগারেশন (`.env.local`)
`.env.local.example` ফাইলটি কপি করে `.env.local` তৈরি করুন:
```bash
cp .env.local.example .env.local
```

`.env.local` ফাইলে প্রয়োজনীয় মান দিন:
```env
# Supabase প্রজেক্ট সেটিংস (Supabase ড্যাশবোর্ডের Settings -> API থেকে প্রাপ্ত)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key

# কর্মকর্তা ড্যাশবোর্ডের ডেমো পাসকোড (যেমন: 1234)
OFFICER_PASSCODE=1234
```

> ⚠️ **নিরাপত্তা সতর্কতা**: সার্ভিস রোল কি বা গোপন পাসকোড কখনো গিটহাবে বা ক্লায়েন্ট কোডে পুশ করবেন না। এগুলো শুধুমাত্র `.env.local` ফাইলে সংরক্ষিত থাকবে।

### ৪. ডাটাবেস টেবিল ও সিড ডেটা মাইগ্রেশন (Supabase SQL Editor)
Supabase ড্যাশবোর্ডের **SQL Editor**-এ গিয়ে নিচের ৩টি ফাইলের কোড ক্রমানুসারে রান করুন:
1. `supabase/schema.sql` — মূল টেবিল তৈরি (`khatian`, `deed`, `land_status`)।
2. `supabase/seed.sql` — ৯টি টেস্ট কেস (দাগ ১০১ থেকে ১০৯) এর শতভাগ ডেমো ডেটা সিডিং।
3. `supabase/demo.sql` — ডেমো ট্যাম্পারিং ল্যাবের জন্য `original_area` কলাম মাইগ্রেশন।

### ৫. অ্যাপ্লিকেশন চালু করা
```bash
# ডেভেলপমেন্ট মোডে রান করতে:
npm run dev

# প্রোডাকশন বিল্ড ও রান করতে:
npm run build
npm run start
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।

### ৬. টেস্ট স্যুট রান করা
সিস্টেমের ৯টি সিডেড কেস এবং ক্রিপ্টোগ্রাফিক ভেরিফিকেশন ইঞ্জিন টেস্ট করতে:
```bash
node scripts/test-cases.mjs
```
*ফলাফল: ১১টি লাইভ ডাটাবেস টেস্ট কেস শতভাগ পাস করবে।*

## 📊 ব্যবহৃত ডেটা সংক্রান্ত ঘোষণা (Data Policy)

- **শতভাগ ডেমো ডেটা**: এই প্রজেক্টে ব্যবহৃত সকল ব্যক্তি, খতিয়ান, দাগ, দলিল ও মৌজা ("কাল্পনিক মৌজা") সম্পূর্ণরূপে কাল্পনিক।
- **কোনো বাস্তব সংবেদনশীল তথ্য নেই**: কোনো নাগরিকের জাতীয় পরিচয়পত্র (এনআইডি), ফোন নম্বর, গোপন দলিল বা বাস্তব সম্পত্তির তথ্য এতে নেই।
- **কোনো স্ক্র্যাপিং নেই**: সরকারি কোনো রিয়েল সার্ভার বা প্রাইভেট ডাটাবেস স্ক্র্যাপ করা হয়নি।

- **ChatGPT** (OpenAI) — বাংলা নাম ভ্যারিয়েশন অ্যালগরিদম ও ট্রাফিক লাইট ইউজার এক্সপেরিয়েন্স ডিজাইন।

## 🔑 কর্মকর্তা ডেমো পাসকোড দ্রষ্টব্য

কর্মকর্তা পোর্টাল (`/officer`) অ্যাক্সেস করার জন্য একটি সরল পাসকোড সিস্টেম ব্যবহার করা হয়েছে, যাতে মূল্যায়নের সময় পরীক্ষক সহজে ঢুকে রেজিস্ট্রেশন, নামজারি ও জালকরণ ডেমো পরীক্ষা করতে পারেন। এটি ফুল প্রোডাকশন আইডেন্টিটি সিস্টেম নয়; পরিবেশ ভ্যারিয়েবলে `OFFICER_PASSCODE` এর মাধ্যমে পাসকোড পরিবর্তন করা যায়।

## 🔮 সীমাবদ্ধতা ও ভবিষ্যৎ পরিকল্পনা (Limitations & Future Work)

1. **সরকারি সেন্ট্রাল এপিআই ইন্টিগ্রেশন**: ভূমি মন্ত্রণালয়ের ই-পর্চা, ই-নামজারি এবং রেজিস্ট্রেশন অধিদপ্তরের সার্ভারের সাথে সরাসরি কানেক্টিভিটি।
2. **পূর্ণাঙ্গ ডিজিটাল নামজারি (Full e-Mutation Workflow)**: সহকারী কমিশনার (ভূমি) এবং ইউনিয়ন ভূমি সহকারী কর্মকর্তার ডিজিটাল স্বাক্ষর (ডিজিটাল সাইন সার্টিফিকেট) অন্তর্ভুক্তি।
3. **ওআইসিআর (OCR) দলিল রিডার**: পুরনো কাগুজে দলিলের স্ক্যান কপি বা ছবি আপলোড করলে কৃত্রিম বুদ্ধিমত্তার মাধ্যমে দাগ, খতিয়ান ও চৌহদ্দি স্বয়ংক্রিয়ভাবে টেক্সটে রূপান্তর।
4. **জাতীয় পরিচয়পত্র ও এসএসও (MyGov SSO)**: নাগরিকের জাতীয় পরিচয়পত্র (NID) ভেরিফিকেশন এবং বায়োমেট্রিক নিরাপত্তা।
5. **এআই ব্যাখ্যা ও আইনি পরামর্শদাতা**: দলিলের কোনো শর্ত বা আদালতের মামলার বিবরণ সাধারণ নাগরিকের বোধগম্য সরল বাংলা ভাষায় বুঝিয়ে দেওয়ার জন্য এআই এজেন্ট সহায়তা।
